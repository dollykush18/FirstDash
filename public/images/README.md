# Your images go here

Drop photos in this folder, then point `src/assets/images.js` at them:

```js
restaurantHero: '/images/hero-food.jpg',
```

Paths start with `/images/` (no `public`) because everything in `public/` is
served from the site root.

Tips:
- Export at roughly 1600px wide for hero images, 1000px for cards.
- Use JPG for photos, and compress them (squoosh.app) before uploading.
- Replace the stock defaults with your own project screenshots as soon as you have them.
